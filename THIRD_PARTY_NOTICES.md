# Third-party notices

[English](THIRD_PARTY_NOTICES_EN.md) | 日本語

SendTextToDots自身のsource（`LICENSE` のMIT）とは別に、次の第三者の素材を利用します。第三者の著作権・licenseはそれぞれの権利者に帰属し、MITへ置き換えるものではありません。

## 1. npm package（固定lock）

このrepositoryは `node_modules` を同梱しません。`npm ci` が `package-lock.json` の固定版・integrityでnpm registryから取得し、各packageのlicense本文・著作権表示・NOTICEは取得した各package内にあります。`npm run package` の生成物（`api.zip`・`mcp.tar.gz`）も `node_modules` を含まず、配置先のbuildで同じlockから取得します。

lockの全333 package（runtime・dev・optional。optionalは環境により取得されない）のlicense内訳: MIT 219、Apache-2.0 76、ISC 18、BSD-3-Clause 12、BlueOak-1.0.0 6、0BSD 1、Unlicense 1。いずれも利用・改変・再配布を許すpermissive licenseです。

- `limiter` 1.1.5（`jwks-rsa` の依存）はlockにlicense fieldがなく、package内の旧形式 `licenses`（MIT）と `LICENSE.txt`（MIT、Copyright (C) 2011 by John Hurliman）で確認しました。
- Apache-2.0のNOTICE fileを持つのは、取得物のうち `typescript` と `@typescript/typescript-<platform>`（いずれもbuild用のdev依存）でした。
- 確認日: 2026-10-23（lock metadataと、Windows x64で取得した `node_modules` の各 `package.json`）。
